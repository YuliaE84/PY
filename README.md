# Руководство по запуску тестов и генерации ответов Allure

1. Убедитесь, что у вас установлены:
- Pytest
- Браузеры Chrome и Firefox
- Webdriver

2. Подключите Allure к проекту:
pip install allure-pytest

3. Запустите тесты и укажите путь к каталогу:
pytest --alluredir allure-result

4. Запустите Allure
allure serve allure-result

5. Посмотрите сформированный отчет
Отчет откроется на локальном сервере в окне вашего браузера. В разделе Suits — список тестов и конкретная информация о каждом из них.
